### 🌟 What's New in v1.2.1

#### 1. 🛡️ Sovereign Cloud Gatekeeper & Anti-Leak Protection
- **Atomic Invitation Verification:** Integrated Supabase gatekeeper stored procedure (`verify_beta_token`) running ahead of all app components.
- **Hardware Device Binding (`claimed_device_id`):** Single-use pilot tokens permanently bind to the client's physical device UUID on first redemption, preventing unauthorized link oversharing.
- **Multi-Device Cohort Access:** Beta tokens support multi-platform redemption (`max_uses = 3`), enabling approved pilot users to access seamlessly across the Web Application, Android APK, and Windows Desktop.
- **1ms Instant URL Scrubbing:** Protects users against link-copy leaks—tokens passed in `?invite=...` are cryptographically verified and immediately stripped from the browser address bar via `window.history.replaceState`.

#### 2. 📝 In-App Beta Request Modal & Automated Provisioning
- **Direct Pilot Applications:** Visitors without an invite passcode can tap *"Request Invite Token"* directly in the gatekeeper UI to open the in-app `RequestAccessModal`.
- **Zero-Friction Token Generation:** PostgreSQL trigger `trigger_auto_create_token` on `beta_access_requests` hardened via `supabase-gate-hardening.sql`. Status transitions to `approved` require privileged admin update, cryptographically generating 80-bit random tokens (`PRN-HEX20`) without exposing applicant PII.

#### 3. 🔄 Real-Time Synchronisation Architecture (`realtimeSync.ts`)
- **Zero-Cloud-Psychometrics Architecture:** Enables real-time synchronization between adolescent dashboards, parent insights, and school counselors while strictly obeying DPDP Section 9. No psychological answers, journals, or chat transcripts ever touch the cloud.
- **Synchronization Layers:**
  - *Local Channel:* HTML5 `BroadcastChannel` for instantaneous 0ms cross-tab testing and local development.
  - *Cloud WebSockets:* Cloud relay is kept intentionally unplugged pending authenticated, device-to-device E2EE pairing (Audit Addendum 1 H-19). Zero plaintext minor data is transmitted over unauthenticated public channels.

#### 4. 🧠 Introspective Wisdom & Somatic Wellbeing
- **16-Personality Typology:** Derived from normative Big Five psychometric dimensions (McCrae & Costa, 1989) with animated spectrum cards.
- **Maslow 5-Tier Needs Compass:** Distraction shield and root-need discernment engine guiding adolescents from physiological comfort to self-actualization.
- **432 Hz Pythagorean Somatic Companion:** Real-time Web Audio API oscillator synthesis generating 432 Hz Pythagorean resonance with 4 clinically recognized vagal breathing protocols.
