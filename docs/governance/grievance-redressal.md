# PRERNA Grievance Redressal Mechanism

## Overview
In accordance with the Digital Personal Data Protection (DPDP) Act, 2023, PRERNA guarantees the right to grievance redressal for all Data Principals (users and their verified guardians). Because PRERNA operates on a strict **local-first** architecture, all psychological and assessment data resides exclusively on the user's device. 

## Filing a Grievance
If a Data Principal believes their rights have been violated, or if the local software is behaving contrary to the consented terms (e.g., suspected unauthorized local tracking), they may file a grievance:

1. **Email:** grievances@prerna-app.example.com
2. **In-App Option:** Users can navigate to `Settings > Privacy > Report a Grievance` to generate a standardized email template.

## Redressal Procedure
1. **Acknowledgment:** All grievances will be acknowledged within 24 hours of receipt.
2. **Investigation:** Because PRERNA has no central database to audit, investigation primarily involves requesting voluntary diagnostic logs from the user's device to verify if the local software functioned incorrectly.
3. **Resolution:** We commit to resolving all grievances within 7 days, providing a transparent technical explanation and, if a bug is identified, a patch timeline.
